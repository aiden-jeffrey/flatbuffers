# Godot Script (gdscript) flatbuffer bindings

The files in the `flatbuffer` directory here are a set of base classes and util
types for use in the construction and access of flatbuffer binaries in gdscript.

The code generated by flatc with the `--gdscript` flag is written against this "runtime".

## Code generation

To generate gdscript bindings for your schema, run something like:

``` sh
flatc --gdscript --gen-object-api -o output schema.fbs
```

If your schema uses includes, then you'll have to append a `--gen-all` to that.

Because gdscript is idiosyncratic, for now you just copy the runtime (`./flatbuffers`) files
directly into your project. There might be a way to add classes defined in gdscript to your
project in a way that aligns normal dependency management, but I don't know what it is.

## Usage

Consult `../tests/gdscript/tests.gd` for some idea of how to use the resulting bindings.
